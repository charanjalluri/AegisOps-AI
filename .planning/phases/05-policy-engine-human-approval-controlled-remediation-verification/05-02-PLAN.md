    Implement gated rollback execution and server in `apps/mcp_deployment/`:
    - In `tools.py`:
      - `rollback_deployment(service: str, target_version: str, proposal_id: str) -> RollbackResult`:
        - Calls `PolicyEngine.validate_execution_allowed(proposal_id)`.
        - If validation fails: raises `ValueError("Policy violation: action rejected. Proposal must be approved by an authorized operator.")`.
        - If approved:
          - Reverts service version state in simulator from `v2.8.1` to `v2.8.0`.
          - Resets connection pool leak (active connections return to baseline 2/50).
          - Updates proposal status in `InvestigationStorage` to `executed` with timestamp.
          - Emits `deployments.events` and `ai.actions` (status='executed').
      - `restart_service(service: str, proposal_id: Optional[str] = None) -> RestartResult`: restarts simulated service process.
    - In `server.py` and `main.py`:
      - Instantiate `BaseMCPServer(name="aegisops-deployment-mcp", version="0.1.0")` on port 8006.
      - Register all 5 tools (`get_current_version`, `get_previous_version`, `get_deployment_history`, `rollback_deployment`, `restart_service`).
      - Provide FastAPI application mounting `POST /mcp`, `GET /health`, `GET /tools`, and `--stdio` runner.
    Update `tests/unit/test_deployment_mcp_tools.py` verifying unapproved proposal rollback is blocked and approved rollback succeeds.
    Write `tests/unit/test_deployment_mcp_server.py` verifying JSON-RPC 2.0 dispatch and error codes.

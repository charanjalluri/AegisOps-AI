## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller → Logs MCP | Inbound tool invocation requesting logs for specific services or time ranges |
| Logs MCP → PostgreSQL | Database queries against `aegisops_db` |
| Logs MCP → LLM Context | Outbound log snippet response |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-07 | Tampering | SQL Injection in Log Queries | high | mitigate | All queries strictly parameterized with asyncpg; no arbitrary SQL execution allowed. |
| T-02-08 | Information Disclosure | Plaintext Secrets in Logs | medium | mitigate | Tool outputs run through `Sanitizer` before being returned to callers or written to audit logs. |
| T-02-09 | Denial of Service | Unbounded Result Sets | medium | mitigate | Query limit hard-capped at 200 items; `TokenBudgetGuard` enforces token truncation. |
| T-02-SC | Elevation of Privilege | Database Mutation | high | mitigate | Queries are restricted to SELECT statements against `raw_logs`. |
</threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM / Caller → MCP Server | Inbound JSON-RPC requests containing tool names and arguments |
| Tool Function → Audit Log | Outbound tool arguments and execution results written to audit log |
| Tool Output → LLM Context | Structured response returned to the caller with token budget constraints |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | Inbound JSON-RPC Parser | high | mitigate | Strict Pydantic validation rejects malformed JSON-RPC payloads and type mismatches. |
| T-02-02 | Denial of Service | Tool Execution Timeout | high | mitigate | Asyncio timeouts enforce hard execution limits (default 30s) preventing hung operations. |
| T-02-03 | Information Disclosure | Tool Audit Log | high | mitigate | `Sanitizer` systematically strips passwords, auth tokens, and connection strings before logging. |
| T-02-SC | Denial of Service | Token Window Exhaustion | medium | mitigate | `TokenBudgetGuard` truncates or paginates responses exceeding token thresholds. |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host → Docker Ports | Local ports (5432, 9092, 29092, 6333, etc.) exposed to developer workstation |
| Container → Container | Docker bridge network (`aegisops_network`) shared across services |
| Environment Variables | Database credentials and API keys passed via `.env` file |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Information Disclosure | `.env` / credentials | high | mitigate | `.env` is listed in `.gitignore`; `.env.example` provides non-production dummy defaults only. |
| T-01-02 | Elevation of Privilege | Docker containers | medium | mitigate | All containers run without privileged flags; read-only mounts used where appropriate. |
| T-01-03 | Denial of Service | Container memory/CPU | medium | mitigate | Resource limits defined on Kafka and Postgres; health checks avoid zombie containers. |
| T-01-SC | Tampering | Python/Docker dependencies | high | mitigate | Strict image version tags used (e.g. `postgres:16.4-alpine`, `apache/kafka:3.7.0`, `kafka-ui:v0.7.2`) instead of `:latest`. |
</threat_model>

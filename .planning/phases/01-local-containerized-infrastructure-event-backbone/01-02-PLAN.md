| Boundary | Description |
|----------|-------------|
| Telemetry Producers → Kafka | Untrusted external services publishing event payloads |
| Kafka Messages → Pydantic | Ingestion boundary converting raw byte payloads into strongly-typed objects |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-04 | Tampering | Event Payload Deserialization | high | mitigate | Strict Pydantic validation rejects malformed, oversized, or prototype-polluting payloads before processing. |
| T-01-05 | Denial of Service | Kafka Topic Exhaustion | medium | mitigate | Topics configured with explicit retention limits (e.g. 7 days or 1GB) and maximum message sizes. |
| T-01-SC | Tampering | Event schema libraries | high | mitigate | Pydantic and Python dependencies pinned in pyproject.toml. |
</threat_model>

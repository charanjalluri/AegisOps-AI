<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller → Incident MCP | Inbound tool requests modifying incident state, hypotheses, or proposals |
| Incident MCP → PostgreSQL | Durable storage of investigation artifacts and audit records |
| Incident MCP → Kafka | Event publishing on `incidents.updated` and `ai.analysis` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-07 | Tampering | Investigation State Corruption | high | mitigate | Strict foreign key constraints and transactional updates in PostgreSQL prevent orphaned evidence or broken hypothesis links. |
| T-03-08 | Repudiation | Unattributed Action Proposals | high | mitigate | Every action proposal includes proposed_by, timestamps, parameters, and risk level. |
| T-03-09 | Elevation of Privilege | Unauthorized Incident Resolution | medium | mitigate | Incident closure mandates summary, root cause, and winning hypothesis attribution. |
| T-03-SC | Information Disclosure | Plaintext Secrets in Evidence | medium | mitigate | Evidence payloads run through `Sanitizer` before storage and event publishing. |
</threat_model>

    - `tools.py`: `DatabaseTools` class:
      1. `get_database_health`: reports connection status, PostgreSQL version, uptime, and database size.
      2. `get_connection_pool`: queries `pg_stat_activity` to report total connections, active, idle, idle in transaction, waiting, and max connections (50).
      3. `get_slow_queries`: retrieves queries exceeding threshold (default 100ms) with execution duration and state.
      4. `get_active_connections`: inspects active non-idle client backends, pids, wait events, query text, and client addresses.
      5. `run_readonly_query`: validates SQL through `SQLMutationValidator`, applies row limit (default 20, max 100), executes with `SET TRANSACTION READ ONLY;`, and paginates through `TokenBudgetGuard`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM / Agent → Database MCP | Unvalidated SQL strings and diagnostic parameters |
| Database MCP → demo_payment_db | Direct SQL execution against the simulated production database |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | SQL Mutation Injection | high | mitigate | `SQLMutationValidator` strictly enforces single-statement read-only SELECT queries; all mutation keywords rejected. |
| T-03-02 | Elevation of Privilege | Transaction Boundary Escalation | high | mitigate | Database queries execute inside explicit `SET TRANSACTION READ ONLY;` transactions. |
| T-03-03 | Denial of Service | Unbounded Diagnostic Dumps | medium | mitigate | Query results clamped to max 100 rows and enforced via `TokenBudgetGuard` (max 4000 tokens). |
| T-03-SC | Information Disclosure | Database Credentials in Prompts | high | mitigate | Database connection string configured via environment variables and masked by `Sanitizer`. |
</threat_model>

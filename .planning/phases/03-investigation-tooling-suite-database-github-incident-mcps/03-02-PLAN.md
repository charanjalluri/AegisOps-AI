<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller → GitHub MCP | Inbound tool requests specifying service names, commit SHAs, or PR numbers |
| GitHub MCP → Git Provider | Local provider mock datasets or external GitHub API |
| GitHub MCP → LLM Context | Outbound diff patches and code change summaries |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04 | Information Disclosure | Git Credentials in Tool Calls | high | mitigate | Zero git credentials in tool arguments; local mock provider requires no tokens; `GITHUB_TOKEN` accessed via env only. |
| T-03-05 | Denial of Service | Unbounded Git Diff Size | medium | mitigate | Diff patches capped and guarded by `TokenBudgetGuard` (max 4000 tokens) to prevent context overflow. |
| T-03-06 | Tampering | Path Traversal via Git Commit IDs | medium | mitigate | Commit SHAs and file paths validated and sanitized; no local filesystem command execution (`git shell`). |
| T-03-SC | Repudiation | Change Attribution | low | mitigate | Every commit record includes immutable author, timestamp, and SHA identifiers. |
</threat_model>

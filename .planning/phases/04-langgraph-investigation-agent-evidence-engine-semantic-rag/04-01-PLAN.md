    Implement `QdrantMemoryClient` in `apps/agent/memory/qdrant.py`:
    - Asynchronous HTTP client using `httpx.AsyncClient` pointing to `QDRANT_URL` (default `http://localhost:6333`).
    - Core methods:
      1. `ensure_collection(collection_name: str = "aegisops_knowledge")`: checks or creates collection with 384-dim Cosine vector configuration.
      2. `upsert_documents(documents: List[KnowledgeDocument])`: embeds texts and upserts points with payload metadata.
      3. `search(query: str, limit: int = 5, score_threshold: float = 0.5, service: Optional[str] = None, document_type: Optional[str] = None)`: embeds query, filters by payload fields, and returns ranked `List[SearchResult]`.
      4. `get_document(doc_id: str)`: fetches single document by ID.
      5. `count()`: returns document count.
    - In-Memory Mock Store Fallback:
      - If Qdrant is unreachable or `offline_mode=True`, stores vectors in an in-memory dictionary and performs exact cosine similarity search over stored vectors.
      - Ensures zero flakiness during tests or standalone demonstrations.
    Update `tests/unit/test_qdrant_client.py` testing collection creation, upsert, similarity search, payload filtering, and fallback mechanisms offline.

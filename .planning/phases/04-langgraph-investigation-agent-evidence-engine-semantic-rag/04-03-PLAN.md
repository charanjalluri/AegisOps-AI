<task type="auto">
  <name>Task 2: LangGraph cyclic state machine orchestrator</name>
  <files>apps/agent/orchestration/state.py, apps/agent/orchestration/graph.py, tests/unit/test_investigation_state_machine.py</files>
  <action>
    Implement the cyclic investigation state machine in `apps/agent/orchestration/`:
    - `state.py`: `InvestigationState` dataclass/Pydantic model holding incident context, hypotheses, canonical evidence list, tool execution history, budget state, and current phase.
    - `graph.py`: `InvestigationGraph` state machine orchestrator:
      1. Node `understand_incident`: receives `IncidentEvent`, extracts service/symptoms, initializes candidate hypotheses.
      2. Node `retrieve_knowledge`: queries Qdrant semantic memory, extracts similar historical incidents as initial evidence.
      3. Node `plan_information`: determines missing facts needed to prove or refute competing hypotheses.
      4. Node `select_tool`: selects next MCP tool (Logs MCP, Database MCP, GitHub MCP).
      5. Node `execute_tool`: invokes tool (via in-process dispatcher or MCP client), records execution history, checks budget.
      6. Node `evaluate_evidence`: normalizes result into `CanonicalEvidence` via `EvidenceNormalizer`, updates `HypothesisEngine`.
      7. Conditional Edge `check_convergence`:
         - If winning hypothesis confidence >= 85% with multi-source corroboration -> route to `synthesize_rca`.
         - If budget exhausted -> route to `synthesize_rca`.
         - Else -> cycle back to `plan_information`.
      8. Node `synthesize_rca`: compiles structured RCA report.
    - Handles tool errors gracefully by adding failure evidence and continuing investigation cycle without crash.
    Write `tests/unit/test_investigation_state_machine.py` verifying full cycle from incident intake through tool execution, evidence convergence, budget limit termination, and offline execution.
  </action>
  <verify>
    <automated>.venv\Scripts\python -m pytest tests/unit/test_investigation_state_machine.py -v</automated>
    <fails_when>non-zero exit code or cyclic loop fails to converge or handle budget limits</fails_when>
  </verify>
  <done>
    `InvestigationGraph` executes cyclic investigation, gathers multi-tool evidence, converges on root cause, and handles budget bounds.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-07 | Denial of Service | Infinite Tool Invocation Loop | high | mitigate | `InvestigationBudget` strictly terminates execution when 20 tool calls, 300s timeout, or 5 expensive operations are reached. |
| T-04-08 | Elevation of Privilege | Autonomous Direct Action Execution | high | mitigate | Investigation Agent only generates `ActionProposal` with status `proposed`; never executes actions directly (enforced in Phase 5 policy gates). |
